# Исторические архивы Developer Edition

Откройте **Архив и система → Центр исторических архивов**. Выберите CSV или ZIP и нажмите **Импортировать и обработать**. Обработка запускается автоматически после записи оригинала и задания в IndexedDB. Хэш SHA-256 предотвращает создание второй копии тех же байтов. Центр показывает обработанные файлы и записи, предупреждения, ошибки и кандидатов на совпадение.

## Хранение и контроль качества

- Переход с версии 2 на 3 сохраняет оригиналы и регистрирует задания для них при первом запуске. На том же адресе, в том же браузере и профиле повторный импорт не нужен. Другой домен или профиль имеет собственную IndexedDB.
- SHA-256 проверяется по сохранённому оригиналу. ZIP поддерживает обычные несегментированные архивы без шифрования с методами Stored и Deflate. Перед обработкой каждого CSV из ZIP проверяются размер и CRC-32. Лимит оригинала и суммарного размера CSV после распаковки — 100 МиБ каждый. Каждый CSV внутри ZIP должен иметь поддерживаемую схему. Лишние файлы других форматов пропускаются. Для обоих форматов используется UTF-8.
- Конвейер сохраняет производные записи по ключу «архив / CSV / номер записи», исходные признаки результата и предупреждения о качестве. Строки с неверным числом полей сохраняются с пометкой. Без счёта и явных признаков форфейта, отказа, дисквалификации или прерывания исход по счёту остаётся неизвестным.
- Кандидаты определяются по повторному ID матча или совпадению даты, турнира и пары ID игроков в рамках пространства исходного источника. При неизвестном источнике поиск ограничен одним импортом. Выбор источника служит подсказкой, поэтому любое совпадение требует ручной оценки. Можно указать решение по каждой паре отдельно. Старые решения остаются в исходном реестре и переносятся на новую пару, если совпадают ID матчей и номера записей.
- Для пакетной записи используется одна транзакция IndexedDB на 250 записей. Пауза прекращает работу на границе транзакции. После закрытия приложения прерванная работа продолжается при открытии той же Developer Edition. Явная пауза сохраняется до нажатия **Продолжить**. При возобновлении анализатор повторно читает CSV до сохранённой позиции, сохраняя только новые результаты.
- Одновременно выполняется одно задание на адрес сайта. На Android обработка зависит от жизненного цикла вкладки или PWA. Место для оригинала, записей и индексов предоставляет браузер. При нехватке места ошибка отображается в карточке и остаётся доступна команда **Повторить**.
- Производные записи и решения доступны только в локальном историческом хранилище. Допуск к прогнозной модели требует отдельного решения. PR #192 и задача отсутствующих пар игроков отложены.
