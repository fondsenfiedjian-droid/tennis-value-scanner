## 3. Scope limitation — important

The current retrospective frame is **ATP Tour and WTA Tour main-draw singles only**, filtered by pre-event top-150 ranking. It is not a complete frame for the Tennis Value Scanner's wider competition universe.

It currently excludes:
- ATP Challenger;
- WTA 125;
- ITF World Tennis Tour;
- qualifying matches;
- doubles;
- team competitions.

Therefore, results from this study cannot be generalized to Challenger, WTA 125 or ITF players. Those circuits need separately declared event lists, ranking/entry eligibility rules, and source-availability reporting before they can be combined with the main-tour sample. Do not silently mix ranking systems or event tiers.

## 4. Remaining extraction blockers

Before a valid denominator can be reported, the research still needs:
1. Official singles draw/result match rows for every included event.
2. Stable player identifiers and match identifiers.
3. The last official ATP/WTA ranking snapshot published before each event, not current rankings or post-event rankings.
4. Symmetric player–match rows for both participants.
5. Explicit counts for missing draws, missing identifiers, unavailable ranking snapshots, withdrawals and walkovers.
6. A frozen outcome-blind sample before source review begins.

A calendar list is not a match sample. The present research log remains exploratory until these joins are complete.
